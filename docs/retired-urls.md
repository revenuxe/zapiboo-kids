# Retired URLs

These legacy vehicle, repair and materials URLs return HTTP 410 Gone with no redirect to the kids marketplace. Deploy this change before submitting removal requests.

## Search Console

Use Removals > New request > Temporarily remove URL. For the old groups, the following narrowly scoped URL prefixes cover the retired routes:

- `https://www.zapiboo.com/sell-used-`
- `https://www.zapiboo.com/sell-commercial-vehicle-bangalore`
- `https://www.zapiboo.com/repair`
- `https://www.zapiboo.com/materials`

Choose the option to remove all URLs with the specified prefix when removing a group. Check the actual indexed URLs for HTTP/non-www variations and submit those variants if needed. Do not submit the site root or current `/sell/`, `/areas/` or `/pickup` URLs.

Search Console removals are temporary (about six months); the permanent 410 responses allow Google to remove these URLs after recrawling. These URLs are absent from the sitemap. Do not block them in robots.txt: Google must be able to fetch the removal response.

Google guidance: https://developers.google.com/search/docs/crawling-indexing/remove-information
